# Varshini S — Immersive Portfolio

This is Varshini's portfolio, built directly from the same HTML, CSS, JavaScript, scroll interactions, and two-path opening experience as the reference portfolio. The visual design has intentionally not been redesigned; the personal content, projects, research, profile photo, certificate images, and résumé have been swapped for Varshini's.

## Run locally

1. Extract this folder.
2. Open it in Visual Studio Code.
3. Use the **Live Server** extension, or open `index.html` directly in a browser.

No package installation or build command is required.

## Publish with GitHub Pages

1. Create a new public repository on Varshini's GitHub account.
2. Upload all files and the `assets` folder, keeping the folder structure intact.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. Wait for deployment and open the Pages URL shown in repository settings.

## Content structure

- `script.js`: interactions, the Hiring/Curious paths, the independent dark/light theme toggle, and scroll effects; preserved with Varshini's profile copy.
- `portfolio-data.js`: the four public GitHub project cards and certificate/publication cards.
